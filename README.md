# PPTX Skill

Codex skill for creating, editing, templating, and QAing PowerPoint presentations.

This package includes:

- `SKILL.md`: trigger rules and workflow overview
- `pptxgenjs.md`: create-from-scratch guidance using PptxGenJS
- `editing.md`: template-based editing workflow
- `assets/huawei_ppt_master.pptx`: bundled Huawei-style master
- `scripts/`: helper scripts for templating, packing, validation, thumbnails, and preview export
- `references/`: style guidance

Default behavior creates dense Huawei-style executive slides when no other brand or template is specified.
